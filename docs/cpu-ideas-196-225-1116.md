# 30 new CPU ideas (#196-#225): codegen, machine copies, natives (2026-11-16)

The user (2026-11-16, after the console breakdowns): "come up with 30 new non-exact or exact codegen/machine copy ideas in
main chat so we can speed up performance". Written from the day's console profiles of the 15 ms build
(docs/cpu-breakdown-15ms-build-1116.md, docs/cpu-frame-chain-functions-1116.md) and the disassembly of its hottest
copies, and checked against every list on record (codegen-ideas-3 CG-01..40, #100-#195, the near-exact 50, the
moonshots M-01..50, the vector ideas). Where an idea builds on a listed one, the line says what is new.

**Kinds:** *exact* (the same results), *inaudible* (audio only, the user's rule: may cheat where no one can hear),
*timing* (the same results, only when things run), *measure* (a census or an A/B decides first).
**ms**: CPU a frame at ~28 fps, estimates. The frame chain (Game Master + the frame jobs) sets the frame rate; audio
shares the cores with it (every audio ms freed helps through JQ Worker 4).
